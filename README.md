# PipTimer

Picture-in-Picture で動作するタイマーアプリケーション

## 機能

### 1. タイマー機能
- ユーザが時間、分、秒を設定可能
- 設定後、開始ボタンでカウントダウン開始
- プログレスバー（円形）で残り時間を視覚的に表示

### 2. Picture-in-Picture 機能
- PiP ボタンでタイマーを Picture-in-Picture モードで表示
- キャンバスベースのリアルタイム描画
- 円形プログレスバーで進行状況を表示
- 色の変化で時間経過を視覚的に表現
  - **青**: 通常状態（残り50%以上）
  - **黄**: 注意状態（残り50%〜25%）
  - **赤**: 警告状態（残り25%未満または超過時）

### 3. ダークモード対応
- ライトモード（デフォルト）とダークモードに対応
- ヘッダーの太陽/月アイコンで切り替え可能
- 設定は localStorage に保存
- システムカラースキーム設定にも対応

### 4. タイマー制御
- **開始**: タイマー開始
- **一時停止/再開**: タイマーを一時停止・再開
- **停止**: タイマーを停止し、入力画面に戻る
- **PiP**: Picture-in-Picture モードで表示

### 5. サウンド機能
- 最後の3秒間にビープ音をプレイ
- タイマー完了時に完了音をプレイ
- Web Audio API を使用

### 6. カウントアップ機能
- タイマー完了後、自動的にカウントアップを開始
- 超過時間を表示

## 使用方法

1. **ブラウザで開く**
   ```bash
   python3 -m http.server 8000 --directory src
   ```
   その後、`http://localhost:8000` にアクセス

2. **タイマー設定**
   - 時間、分、秒を入力
   - 「開始」ボタンをクリック

3. **タイマーコントロール**
   - 「一時停止」で一時停止/再開
   - 「停止」でリセット
   - 「PiP」で Picture-in-Picture モードに移行

4. **テーマ切り替え**
   - ヘッダーのアイコンをクリック

## 技術仕様

### 使用技術
- **HTML5** - セマンティック構造
- **CSS3** - グリッドレイアウト、カスタムプロパティ、アニメーション
- **JavaScript (Vanilla)** - 状態管理、Web Audio API、Canvas API
- **Web APIs**:
  - Picture-in-Picture API
  - Canvas API
  - Web Audio API
  - localStorage API
  - requestAnimationFrame

### ディレクトリ構成
```
src/
├── index.html           # メインHTML
├── script/
│   └── app.js          # メインアプリケーション（全機能実装）
├── style/
```

### ファイル説明

#### index.html
- タイマー入力フォーム
- タイマー表示エリア
- プログレスバー（円形）

- Picture-in-Picture用キャンバス（非表示）

#### script/app.js
- **状態管理**: タイマー状態、テーマ設定
- **タイマーロジック**: カウントダウン、カウントアップ、一時停止
- **UI更新**: 時間表示、プログレスバー、ステータス表示
- **Picture-in-Picture**: キャンバス描画、動画ストリーム生成
- **テーマ管理**: ライト/ダークモード切り替え
- **サウンド**: Web Audio API による効果音再生

#### style/main.css
- **CSS カスタムプロパティ**: ライト/ダークモードのカラー定義
- **レイアウト**: Flexbox、グリッド
- **プログレスバー**: SVG円形プログレスバーのスタイル
- **レスポンシブ**: モバイル対応

- Chrome OS 最新版での動作を想定

## 開発ノート

### プログレスバーの色判定
```javascript
// 時間経過に応じて色を変更
- 残り時間 > 50%: 青（#007bff）
- 残り時間 50% ~ 25%: 黄（#ffc107）
- 残り時間 < 25% または 超過: 赤（#dc3545）
```

### Picture-in-Picture の実装
- Canvas API でタイマーを描画
- `captureStream()` で動画ストリームを生成
- `requestPictureInPicture()` を使用して PiP にレンダリング
- `leavepictureinpicture` イベントでクリーンアップ

### パフォーマンス最適化
- タイマー の更新: 1秒ごと（正確性のため）
- プログレスバー アニメーション: `requestAnimationFrame` で 60fps
- PiP キャンバス更新: 100ms ごと（30fps）
